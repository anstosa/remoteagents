[microsoft/vscode-codicons](https://github.com/microsoft/vscode-codicons).

- Upstream revision: `6b53088f5c55bce7107fb579765364f59cd4ad5d`

- SVG files are unmodified upstream copies. RAC uses CSS masks to apply its existing icon color at 16px.

This self-hosted subset covers folders, generic files, source code, structured
configuration, text, PDF, media, archives, binary files, and symbolic links. No
icon font, additional package, or external runtime request is required.
